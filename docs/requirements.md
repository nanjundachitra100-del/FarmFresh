# FarmFresh

## Project Purpose

FarmFresh is a platform that connects farmers directly with customers, allowing customers to discover and purchase fresh agricultural products directly from farmers.

## Customer Features

- Customer registration and login
- Browse available farm products
- Search and filter products
- View product details
- View farmer information
- Add products to cart
- Place orders
- Make payments using x402
- View order status
- View previous orders
- Give ratings and reviews

## Farmer Features

- Farmer registration and login
- Create and manage farmer profile
- Add farm products
- Upload product images
- Set product price
- Set available quantity
- Edit product details
- Delete products
- Manage inventory
- View customer orders
- Update order status
- View sales information

## Admin Features

- Admin login
- Manage customers
- Manage farmers
- Manage products
- Manage orders
- Monitor payments
- Manage reported reviews
- View platform statistics

## Product Features

- Farmers can add products
- Each product has a name, description, price, quantity and category
- Farmers can upload product images
- Customers can view product details
- Customers can search and filter products
- Customers can view the farmer who sells the product
- Customers can see product availability
- Farmers can update product information
- Farmers can remove products

## Order Features

- Customers can add products to their cart
- Customers can update cart quantities
- Customers can remove products from the cart
- Customers can view the total order amount
- Customers can place an order
- Customers can view their previous orders
- Customers can track order status
- Farmers can view orders for their products
- Farmers can update order status
- Orders should have a unique order ID

## Payment Features

- Customers can proceed to checkout
- Customers can view the total payment amount
- The platform will integrate the x402 payment protocol
- Payment should be verified before confirming an order
- The system should store payment status
- Orders should only be confirmed after successful payment
- Customers should be able to view their payment status
- The payment module should be designed so it can be updated or replaced later

## Delivery Features

- Customers can provide a delivery address
- Customers can view the status of their order
- Farmers can update the order status
- The system should support delivery status updates
- Customers should receive updates when the order status changes
- The delivery module should be designed so that delivery tracking can be added later

## Review Features

- Customers can rate products and farmers
- Customers can write reviews after completing an order
- Customers can view existing reviews
- Farmers can view reviews received from customers
- Admin can manage reported reviews
